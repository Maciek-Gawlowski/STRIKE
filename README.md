# STRIKE - Sea Trout Fishing App

Cross-platform mobile app for anglers. Log trips, track catches, and see a community bite-map. Built end-to-end.

**Built with:** React Native · Expo · TypeScript · Supabase · REST APIs (live weather & water-level data)

## Features
- Automatic GPS trip tracking
- Log contacts, follows, and catches with photo, species, length, weight
- Community heatmap showing where fish are biting
- Season stats and personal insights

**Status:** shipping to real users — targeting alpha with ~20 anglers.
